
**Основні Теми та Ідеї:**

1.  **"Обряд Ініціації":** Початкове програмне налаштування пристроїв є необхідним етапом після фізичного підключення, щоб "дати їм унікальні імена (IP-адреси) і навчити базових правил поведінки (пароль!)".
2.  **Пошук Пристроїв у Мережі:** Існує кілька методів пошуку нових або існуючих пристроїв у локальній мережі:
	-   **Фірмові Утиліти Виробника (Найкращий):** Рекомендований спосіб. Утиліти (SADP Tool, ConfigTool, IP Utility, EZTool) сканують мережу незалежно від IP-адреси пристроїв, бачать "неактивовані" пристрої, дозволяють їх активувати та змінювати IP. "Це найзручніший спосіб для первинного налаштування кількох пристроїв."
	-   **Веб-інтерфейс Роутера:** Можливість знайти пристрої у списку DHCP-клієнтів або ARP-таблиці за їх MAC-адресою. Потрібно знати MAC-адресу пристрою.
	-   **IP-Сканери:** Загальні утиліти для сканування діапазону IP-адрес. Бачать лише пристрої, що вже мають IP у сканованій підмережі.
	-   **Дефолтна IP-адреса:** Можливість прямого доступу через браузер, якщо відома заводська IP та комп'ютер у тій самій підмережі.

3.  **Перший Вхід та Дефолтні Паролі:** Після знаходження пристрою, доступ здійснюється через веб-браузер за його IP-адресою. Потрібно ввести логін та пароль.

	-   Дефолтні дані (admin/admin, admin/12345 тощо) наведені в інструкції або на наклейці, але їх **ТРЕБА ЗМІНИТИ!**
	-   Багато сучасних пристроїв вимагають **Активації** – створення нового пароля при першому підключенні, часто через фірмову утиліту або веб-інтерфейс.
	-   **Активація та Зміна Пароля: Безпека Перш за Все:**Це **НАЙВАЖЛИВІШИЙ** крок для безпеки. "Залишати стандартний пароль... – це як залишити двері квартири навстіж".
	-   При активації або зміні пароля потрібно **Придумати складний пароль!** (мін. 8-10 символів, різні регістри, цифри, спецсимволи). Він має бути унікальним.
	-   Рекомендовано використовувати функції відновлення пароля (email, секретні питання).
	-   Після зміни пароля на камері, необхідно оновити його в налаштуваннях NVR для підтримки зв'язку.
	-   Складні паролі також потрібні для будь-яких додаткових користувачів.
	-   Нехтування цим пунктом – "прямий шлях до проблем в майбутньому".

4.  **Оновлення Прошивки (Firmware):** Прошивка – це "мозок" пристрою (вбудоване ПЗ).

	-   **Навіщо оновлювати:Безпека (НАЙГОЛОВНІША причина!):** Закриття вразливостей. "Не оновлювати прошивку = залишати ще одні двері відкритими."
		-   Виправлення помилок (багів).
		-   Додавання нових функцій.
		-   Покращення продуктивності та стабільності.
		-   Покращення сумісності.
-   **Як оновлювати:** Перевірити поточну версію через веб-інтерфейс.
	-   Знайти нову прошивку **тільки на офіційному сайті виробника!** (Ніколи не качати з інших ресурсів!).
	-   Уважно прочитати інструкції та примітки до релізу.
	-   Процес: Зазвичай через веб-інтерфейс, рідше через утиліту або TFTP (аварійний спосіб).
	-   **НЕ ВИМИКАТИ ЖИВЛЕННЯ** під час оновлення ("Це гарантований спосіб отримати 'цеглину'." Рекомендовано використовувати UPS).
	-   **Коли оновлювати:** При першому налаштуванні, регулярно (раз на кілька місяців), при виникненні проблем.

5.  **Налаштування Мережевих Параметрів (IP, Маска, Шлюз, DNS):** Пристрою потрібна "правильна 'прописка' в нашій мережі".

-   **Де налаштовувати:** У веб-інтерфейсі ("Мережа", "TCP/IP") або через фірмову утиліту.
-   **Вибір Режиму:** DHCP: Автоматичне отримання адреси (простіше, але може змінюватись; рекомендовано DHCP Reservation на роутері).
-   **Static (Статичний):** Ручне прописування параметрів. **Рекомендований варіант для стабільності.**
-   **Параметри для Static:** IP-адреса: Унікальна, з запланованого діапазону, не повинна дублюватись.
-   Маска Підмережі: Визначає розмір мережі (зазвичай 255.255.255.0). Має бути однакова для всіх пристроїв у підмережі.
-   Основний Шлюз (Default Gateway): IP-адреса роутера для виходу в інші мережі/інтернет.
-   DNS-Сервер(и): Потрібні для перетворення доменних імен в IP. Може бути IP роутера або публічні сервери (Google, Cloudflare).
-   Без правильних Шлюзу та DNS пристрій не зможе підключатись до інтернет-сервісів (хмара, NTP).
-   Після налаштування **потрібно перевірити**, чи не помилився в цифрах і чи немає дублювання IP.

6.  **Налаштування Часу та Дати (NTP Синхронізація):** Критично для актуальності записів та роботи автоматики. "Неправильний час на камері чи NVR – це катастрофа для архіву."

-   **Правильний шлях – NTP:** Синхронізація з точними серверами часу через інтернет.
-   **Ключові кроки:** Вибрати правильний Часовий Пояс (для України (GMT+02:00) Kyiv).
-   Увімкнути Літній/Зимовий Час (**DST**).
-   Увімкнути синхронізацію через NTP.
-   Вказати Адресу NTP-сервера (pool.ntp.org, time.google.com, time.cloudflare.com). Потрібні правильно налаштовані Шлюз та DNS.
-   **Ручне встановлення (План Б):** Тільки при відсутності інтернету, але вимагає регулярної корекції.
-   **Альтернативи:** Синхронізація часу NVR з камерами або клієнтським ПЗ (менш надійно, ніж NTP).
-   **Перевірка:** Переконатись, що відображається правильний час після синхронізації.

7.  **Налаштування OSD (On-Screen Display):** "Ставимо 'Штамп' на Відео". Текст, що "впалюється" у відеокадр.

-   **Навіщо:** Ідентифікація камери, фіксація Часу/Дати (найголовніше для доказової бази), додаткова інформація.
-   **Обов'язковий Мінімум:**Назва Камери: Логічна, відображає місцезнаходження ("Не залишай дефолтні Camera 01!"). Увімкнути відображення.
-   Дата та Час: Увімкнути відображення, вибрати формат.
-   **Де налаштовувати:** У веб-інтерфейсі камери (краще) або NVR.
-   **Перевірка:** Переконатись, що OSD видно на відео, читабельне і не заважає огляду.
-   Точний час через NTP та інформативне OSD – "ознака професійного налаштування системи".

**Найважливіше:**

-   Початкове програмне налаштування є обов'язковим і не менш важливим, ніж фізичне підключення.
-   **Фірмові утиліти виробника** – найкращий інструмент для початкового пошуку, активації та налаштування IP багатьох пристроїв одночасно.
-   **Негайне створення/зміна стандартного пароля на складний та унікальний є критично важливим кроком для безпеки.** "Залишати стандартний пароль... – це як залишити двері квартири навстіж".
-   **Регулярне оновлення прошивки** – це в першу чергу захід безпеки, що закриває вразливості. Оновлювати **тільки з офіційних сайтів** і **не вимикати живлення** під час процесу.
-   **Статичні IP-адреси** рекомендовані для стабільної роботи камер та NVR. Правильне налаштування **Шлюзу та DNS** є необхідним для роботи з інтернет-сервісами.
-   **Синхронізація часу через NTP** є найкращим та найнадійнішим способом забезпечити правильний час на записах, що критично для архіву та доказової бази.
-   **Налаштування OSD** (назва камери + дата/час) є обов'язковим для зручної ідентифікації камер та створення інформативного архіву.

Ці кроки складають основу безпечного та коректного функціонування системи відеоспостереження і не мають ігноруватися.


 ### Ключові Терміни:

-   **DHCP-клієнти (DHCP clients):** Пристрої в мережі, які отримують IP-адресу та інші мережеві налаштування автоматично від DHCP-сервера (зазвичай на роутері).
-   **ARP-таблиця (ARP table):** Таблиця на мережевих пристроях (наприклад, роутері), що зберігає відповідність між IP-адресами та MAC-адресами пристроїв у локальній мережі.
-   **MAC-адреса (MAC address):** Унікальний фізичний ідентифікатор мережевого пристрою, "вшитий" виробником.
-   **TFTP (Trivial File Transfer Protocol):** Простий протокол передачі файлів, який іноді використовується для аварійного відновлення або оновлення прошивки пристроїв.
-   **TCP/IP (Transmission Control Protocol/Internet Protocol):** Основний набір протоколів, на яких базується робота інтернету та більшості сучасних комп'ютерних мереж.
-   **DHCP Reservation:** Функція на DHCP-сервері (роутері), що дозволяє "забронювати" певну IP-адресу для конкретного пристрою (за його MAC-адресою), щоб він завжди отримував саме цю адресу автоматично.
-   **Static (Статичний) IP (Static IP):** IP-адреса, яка призначається пристрою вручну та залишається незмінною. Рекомендований варіант для серверного обладнання, камер та реєстраторів.
-   **Маска Підмережі (Subnet Mask):** Параметр, що визначає, яка частина IP-адреси належить до адреси мережі, а яка – до адреси вузла в цій мережі (наприклад, 255.255.255.0).
-   **Основний Шлюз (Default Gateway):** IP-адреса маршрутизатора в локальній мережі, через який пристрої отримують доступ до інших мереж, зокрема до інтернету.
-   **DNS-Сервер (DNS Server - Domain Name System Server):** Сервер, що перетворює доменні імена сайтів (наприклад, https://www.google.com/search?q=google.com) в IP-адреси, зрозумілі комп'ютерам.
-   **NTP (Network Time Protocol):** Протокол для синхронізації часу комп'ютерів та інших пристроїв у мережі з точними серверами часу через інтернет.
-   **Літній/Зимовий Час (DST - Daylight Saving Time):** Практика переведення годинників на одну годину вперед влітку для кращого використання денного світла.
-   **OSD (On-Screen Display / Екранне Меню або Відображення на Екрані):** Текстова інформація (назва камери, дата, час тощо), яка накладається ("впалюється") безпосередньо на відеозображення.
